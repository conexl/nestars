# Nestars Mini App — UI Design Document

> Цель: заменить/дополнить inline-меню бота удобным нативным интерфейсом внутри Telegram (Web App / Mini App).

---

## 1. Общая концепция

- **Single-page mobile-first web app** с нижней навигацией.
- **Авторизация** через Telegram `initData` (проверка на backend, создание/получение пользователя).
- **Тема** автоматически подстраивается под Telegram: светлая/тёмная, CSS-переменные `--tg-theme-*`.
- **Языки**: RU / EN (определяется по `initData.user.language_code`).
- **Основные сценарии**: покупка Stars, покупка Premium, профиль, история заказов, реферальная программа, вывод звёзд.

---

## 2. Структура навигации

Нижняя панель (`BottomNavigation`) с 3 пунктами:

| Иконка | Название | Описание |
|--------|----------|----------|
| 🏠 | **Главная** / Home | Каталог Stars/Premium, быстрый доступ к профилю |
| 📋 | **Заказы** / Orders | История заказов и их статусы |
| 👤 | **Профиль** / Profile | Баланс, статистика, рефералка, вывод |

- Подсказки: 12–13 px, цвет `--tg-theme-hint-color`.

## 5. Пользовательские сценарии (User Flows)

### 5.1 Покупка Stars

1. Пользователь открывает Mini App из бота.
2. Backend проверяет `initData`, создаёт/возвращает профиль.
3. Пользователь нажимает "Купить Stars".
4. Выбирает пакет или вводит произвольное количество.
5. Нажимает "Продолжить".
6. Выбирает получателя (себя / вводит username).
7. Нажимает "Далее".
8. Видит сводку заказа и выбирает способ оплаты.
9. Нажимает "Оплатить".
10. Для внешних способов — открывается ссылка на оплату; для баланса — мгновенное списание.
11. Переход на экран статуса заказа.

### 5.2 Покупка Premium

Аналогичен покупке Stars, но вместо количества выбирается период подписки (3 / 6 / 12 месяцев).

### 5.3 Просмотр профиля и вывод звёзд

1. Пользователь открывает раздел "Профиль".
2. Видит баланс и статистику.
3. Нажимает "Вывести звёзды".
4. Вводит получателя и количество.
5. Подтверждает действие.
6. Backend инициирует вывод.

## 6. Интеграция с ботом

### 6.1 Кнопка открытия Mini App

В главном меню бота добавить кнопку:

```go
{
    Text:   "🛒 Открыть магазин",
    WebApp: &telego.WebAppInfo{URL: cfg.MiniAppURL},
}
```

### 6.2 API для Mini App (предварительный список)

| Метод | Endpoint | Описание |
|-------|----------|----------|
| POST | `/api/miniapp/auth` | Проверка `initData`, возврат профиля |
| GET | `/api/miniapp/catalog/stars` | Каталог Stars |
| GET | `/api/miniapp/catalog/premium` | Каталог Premium |
| POST | `/api/miniapp/orders` | Создание заказа |
| POST | `/api/miniapp/orders/:id/pay` | Инициация оплаты |
| GET | `/api/miniapp/profile` | Профиль и баланс |
| GET | `/api/miniapp/orders` | История заказов |
| POST | `/api/miniapp/withdraw` | Вывод звёзд |

### 6.3 Безопасность

- `initData` проверяется по HMAC-SHA256 с `BOT_TOKEN`.
- Все запросы от Mini App содержат `Authorization: tma <initData>`.
- Backend не хранит seed/cookies пользователя (это остаётся во Fragment API wrapper).

## 7. Открытые вопросы для обсуждения

Перед началом разработки предлагаю уточнить:

1. **Стек фронтенда**:
   - **Вариант A (рекомендован)**: React + TypeScript + Vite — стандарт для Mini Apps, удобно масштабировать.
   - **Вариант B**: Vanilla JS + HTML/CSS — меньше зависимостей, проще деплой, но больше ручной работы.
2. **Функционал MVP**:
   - Все функции бота (Stars, Premium, Profile, Withdraw, Referral, Orders) или ограничиться Stars + Premium + Profile?
3. **Способы оплаты**:
   - Те же, что в боте (Balance, Crypto Bot, ЮKassa, Heleket)? Нужна ли интеграция Telegram Stars Payment внутри Mini App?
4. **Брендинг**:
   - Есть ли логотип/название, которое должно отображаться в шапке? Использовать существующее `menuPhoto`?
